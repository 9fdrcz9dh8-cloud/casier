# Casier : stock et caisse

Gestion de stock, caisse (prix détail et gros), crédits clients, achats fournisseurs et rapports de bénéfice pour un magasin de boissons.
L'application fonctionne sans internet. Les données restent sur chaque appareil.

## Mettre en ligne gratuitement avec GitHub Pages

1. Créez un compte gratuit sur https://github.com, puis un nouveau dépôt **public** nommé `casier`.
2. Cliquez sur **uploading an existing file**, glissez **tous les fichiers de ce dossier**, puis **Commit changes**.
3. Ouvrez **Settings → Pages**. Dans **Branch**, choisissez `main` et `/ (root)`, puis **Save**.
4. Après une ou deux minutes, l'application est en ligne sur `https://VOTRE-NOM.github.io/casier/`.

Autre possibilité : glisser ce dossier sur https://app.netlify.com/drop (compte Netlify gratuit).

## Installer sur un téléphone ou un ordinateur

Ouvrez le lien dans Chrome, puis touchez **Installer** (ou menu de Chrome → **Ajouter à l'écran d'accueil**).
Sur iPhone : Safari → Partager → **Sur l'écran d'accueil**.

## Mettre à jour

Remplacez les fichiers du dépôt par ceux de la nouvelle version. Les appareils la reçoivent au démarrage suivant, quand ils ont internet.

## Données

Chaque appareil garde ses propres données. Faites une sauvegarde chaque semaine (Réglages → Sauvegarde).
« Restaurer une sauvegarde » permet de passer les données d'un appareil à un autre.
